TIME SERIES / QUANT / FEATURE SELECTION — CHEAT SHEET

เป้าหมายจริง:

อย่าถาม: ❌ Feature นี้สัมพันธ์กับ target ไหม

ให้ถาม: ✅ Feature นี้ช่วย “ทำนายอนาคต” ได้ไหม เช่น: Nasdaq วันนี้ → SET
สัปดาห์หน้า

1) Correlation (Pearson)

ใช้ดู: - เคลื่อนไหวไปทางเดียวกันไหม

ข้อเสีย: - ไม่ได้บอกอนาคต - ดูแค่ linear relationship

2) Lag Correlation

ดู: feature[t] vs target[t+1]

เช่น: Nasdaq วันนี้ → SET สัปดาห์หน้า

เริ่มวัด predictive relationship

3) Spearman Correlation

ดู: - ความสัมพันธ์เชิงอันดับ (rank relationship)

เช่น: Spearman = 0.12

ใน finance: 0.10+ = อาจมี signal

แต่ไม่ใช่: “เจอ holy grail”

4) Mutual Information (MI)

ถาม: Feature ให้ข้อมูลกับ target ไหม

จับ nonlinear ได้

5) XGBoost Feature Importance

ถาม: Model ใช้ feature นี้บ่อยแค่ไหน

ข้อเสีย: feature ซ้ำความหมายกันได้

6) Permutation Importance

ถาม: เอา feature ออกแล้ว performance ตกไหม

ถ้าตก: => feature สำคัญ

7) SHAP

ถาม: Feature นี้ดัน prediction ขึ้นหรือลง

เช่น: DXY ↑ → SET prediction ↓

8) Walk-forward Stability (สำคัญมาก)

ถาม: Feature ยังสำคัญข้ามเวลาไหม

2010: EEM สำคัญ

2020: EEM ยังสำคัญ

=> stable signal

Regime คืออะไร

สภาพตลาด:

Bull: ตลาดดี

Normal: ปกติ

Crisis: ตลาดกลัว

Feature สำคัญเปลี่ยนตาม regime

Ensemble คืออะไร

1w model: ขึ้น

4w model: ขึ้น

=> เห็นตรงกัน → trade

ข้อดี: ความแม่นเพิ่ม

Coverage คืออะไร

Coverage = 51%

แปล: มี signal แค่ ~ครึ่งเวลา

Sharpe Ratio

วัด:

ผลตอบแทน / ความเสี่ยง

คร่าว ๆ: <0 = แย่ 0–0.5 = พอใช้ 0.5–1 = เริ่มดี >1 = ดี >2 = ดีมาก

ทำไมข้อมูลเก่าอาจทำให้แย่

ตลาดเปลี่ยน regime

ดังนั้น: ใช้ข้อมูล 20 ปี อาจแย่กว่า ใช้ข้อมูล 7 ปี

เรียก: Regime-aware training window
